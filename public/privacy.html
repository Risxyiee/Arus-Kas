3. Cara Kami Menggunakan Data

Kami menggunakan data Anda untuk tujuan berikut:

  • Menyediakan Layanan: Menjalankan fungsi inti pencatatan keuangan, sinkronisasi data, dan pengelolaan akun.
  • Memproses Pembayaran: Mengelola langganan Pro dan transaksi pembayaran melalui Midtrans.
  • Meningkatkan Layanan: Menganalisis pola penggunaan untuk perbaikan fitur dan pengalaman pengguna.
  • Berkomunikasi: Mengirim pemberitahuan layanan, konfirmasi transaksi, dan informasi akun penting.
  • Keamanan: Mendeteksi dan mencegah penipuan, penyalahgunaan, dan aktivitas tidak sah.

4. Penyimpanan Data

4.1 Paket Gratis: Data transaksi keuangan Anda disimpan secara eksklusif di browser localStorage pada perangkat Anda. Kami tidak memiliki akses ke data ini. Data tidak meninggalkan perangkat Anda.

4.2 Paket Pro: Data transaksi disimpan di Supabase PostgreSQL (cloud) dengan enkripsi at-rest dan transit. Data disinkronkan antara perangkat Anda melalui koneksi terenkripsi.

4.3 Sesi & Cache: Data sesi dan cache disimpan di Cloudflare KV untuk performa dan keamanan. Data ini bersifat sementara dan tidak berisi informasi pribadi langsung.

4.4 Retensi Data:

  • Data akun: Disimpan selama akun aktif. Dihapus dalam 30 hari setelah permintaan penghapusan akun.
  • Data transaksi (Pro): Disimpan selama langganan aktif + 90 hari untuk keperluan laporan. Dapat dihapus lebih awal atas permintaan.
  • Data pembayaran: Disimpan selama 5 tahun sesuai kewajiban perpajakan Indonesia.

5. Keamanan Data

Kami menerapkan langkah-langkah keamanan berikut:

  • Enkripsi Transit: Seluruh komunikasi menggunakan HTTPS/TLS 1.3.
  • Enkripsi At-Rest: Data di Supabase dienkripsi menggunakan AES-256.
  • Row Level Security (RLS): Kebijakan RLS di Supabase memastikan setiap pengguna hanya dapat mengakses data miliknya sendiri.
  • Autentikasi: Menggunakan JWT dengan masa berlaku terbatas dan refresh token yang aman.
  • Audit: Kami melakukan peninjauan keamanan secara berkala terhadap infrastruktur dan kode.

Meskipun demikian, tidak ada sistem yang sepenuhnya bebas risiko. Kami menyarankan Anda untuk tidak membagikan kredensial akun kepada siapapun.

7. Hak Pengguna

Sesuai UU PDP Indonesia, Anda memiliki hak-hak berikut atas data pribadi Anda:

  • Hak Akses: Meminta salinan data pribadi yang kami miliki tentang Anda.
  • Hak Koreksi: Meminta perbaikan data yang tidak akurat atau tidak lengkap.
  • Hak Penghapusan: Meminta penghapusan data pribadi Anda, dengan tunduk pada kewajiban hukum yang berlaku.
  • Hak Portabilitas: Meminta transfer data Anda dalam format yang terstruktur dan dapat dibaca mesin (JSON/CSV).
  • Hak Keberatan: Menolak pemrosesan data untuk tujuan tertentu.

8.3 Anda dapat mengelola cookie melalui pengaturan browser. Namun, menonaktifkan cookie esensial dapat memengaruhi fungsionalitas aplikasi.
